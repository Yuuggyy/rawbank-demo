ETAPE 2: CHAT AI - LE COEUR DE L'APP (5 min)
===================================================

[Aller dans l'onglet "Assistant"]

Démonstration en 3 questions:

Question 1 (Routing):
"Je voudrais financer un projet de transformation agroalimentaire dans le Kasaï"
→ Le Routeur IA oriente automatiquement vers le bon agent
→ L'agent RSE prend le relais et évalue l'impact

Question 2 (RSE/ESG):
"Quel est l'impact environnemental de mon projet de centrale solaire?"
→ Réponse détaillée avec analyse de l'impact
→ Score attribué (0-100)

Question 3 (Comptabilité):
"Quel taux d'intérêt pour un prêt de 75 000 USD sur 5 ans?"
→ L'Agent Comptabilité répond avec les calculs

Points clés à souligner:
- 5 agents IA: Routeur, RSE, Conformité, Commercial, Comptabilité
- Routing automatique par mots-clés
- Réponses en 2-3 secondes (API Groq)
- Scoring automatique des projets (0-100)
- Historique de conversation persistant

"Chaque agent est spécialisé dans un domaine. Le Routeur analyse la question et oriente automatiquement vers l'agent le plus pertinent. Le client reçoit une réponse experte en quelques secondes."

===================================================
ETAPE 5: ARCHITECTURE TECHNIQUE (2 min)
===================================================

Stack technique:
- Frontend: Flutter (mobile + web), Material 3
- Backend: Base44 (fonctions serverless)
- Base de données: Supabase (PostgreSQL, RLS)
- IA: Groq API (LLM, réponses < 3s)
- 9 tables: user_profiles, projects, transactions, chat, KYC, notifications, exchange_rates, admin_users

Architecture multi-agents:
- Routeur IA: orientation et synthèse
- Agent RSE: impact social et environnemental
- Agent Conformité: réglementaire et juridique (BCC, RCCM)
- Agent Commercial: viabilité marché et concurrence
- Agent Comptabilité: analyse financière, DSCR, ROI

===================================================
QUESTIONS ANTICIPÉES
===================================================

Q: Les agents IA utilisent quelle technologie?
R: LLM via l'API Groq (Llama), avec un système de routing par mots-clés. Chaque agent a un prompt système spécialisé dans son domaine. Réponses en moins de 3 secondes.

Q: Les données sont stockées où?
R: Supabase (PostgreSQL hébergé). 9 tables avec Row-Level Security. L'admin accède à toutes les données, les clients ne voient que leurs propres données.

Q: Est-ce que ça marche hors ligne?
R: L'app Flutter fonctionne en mode déconnecté pour l'affichage. Le chat IA nécessite une connexion internet. Les données se synchronisent au retour de la connexion.

Q: Comment ça passe à la production?
R: Il faut: activer l'auth Supabase réelle, intégrer l'API IllicoCash, configurer les notifications push, et enrichir la base de connaissances RAG avec les documents RawBank (politiques de financement, grille tarifaire, etc.)

Q: Coût de fonctionnement?
R: Base44 (backend + IA): crédits selon l'usage. Supabase: gratuit jusqu'à 500MB et 50 000 utilisateurs. Groq: gratuit en phase beta. Coût total estimé: minimal en phase de lancement.
